# 🌙 Moonex

Moonex es un proyecto desarrollado como **Trabajo de Fin de Grado (TFG)**.  
Su objetivo es **una Red Social para que las personas se puedan comunicar de forma sencilla**.

> ⚠️ **Nota:** El despliegue original en Render ya no está activo.  
> Aquí encontrarás el código fuente, la documentación y capturas de pantalla para entender su funcion
